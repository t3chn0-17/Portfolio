# T3CHN0 — Interactive Portfolio

> A personal portfolio designed as an interactive journey through a futuristic spacecraft interface.

This isn't a traditional portfolio website.

Instead of simply scrolling through sections, visitors can **start a journey** through my work, projects, skills, and experience.

## ✦ Concept

The portfolio is built around a spacecraft-travel concept.

The visitor begins at the launch screen and selects:

**`START TRAVELING`**

From there, the interface transitions between different destinations containing the portfolio content.

Each destination represents a different part of my developer profile.

```text
             ┌─────────────────┐
             │     LAUNCH      │
             └────────┬────────┘
                      ↓
                ┌───────────┐
                │   ABOUT   │
                └─────┬─────┘
                      ↓
              ┌───────────────┐
              │    PROJECTS   │
              └───────┬───────┘
                      ↓
                ┌───────────┐
                │   SKILLS  │
                └─────┬─────┘
                      ↓
              ┌───────────────┐
              │    CONTACT    │
              └───────────────┘
```

## ✦ Development

Clone the repository:

```bash
git clone <repository-url>
cd portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## ✦ Design Philosophy

The goal is to make the portfolio feel like an **experience**, not just a collection of webpages.

Visual design, motion, interaction, and performance are treated as part of the interface itself.
